Built and deployed an end-to-end AI-powered recruitment platform with role-based dashboards for **Hiring Managers, HR, and Employees**.

- Built using **Python, FastAPI, React, Azure OpenAI, Azure SQL, Cosmos DB, and Azure Blob Storage**
- Developed an AI chatbot to collect hiring requirements and automatically generate job descriptions and required/preferred skills
- Built HR approval workflows and an Employee Referral Portal

- Worked on cloud deployment, security, and role-based access

### 🏥 AI-Powered Patient Triage Application

Built an AI-powered application to help healthcare staff prioritize patients as **Emergency, Urgent, or Routine**.

- Built using **Python, FastAPI, LangGraph, MCP, Azure OpenAI, and Azure SQL**
- Developed an AI workflow for symptom analysis and patient prioritization
- Implemented MCP tools and REST APIs
- Designed structured and explainable AI recommendations

### 🎥 DeepFake Detector

Developed a deep learning system to detect manipulated videos.

- Built using **Python, TensorFlow, OpenCV, NumPy, InceptionV3, and Scikit-learn**
- Used InceptionV3 for facial feature extraction
- Trained a GRU-based classifier on **323 fake and 77 real videos**
- Optimized preprocessing and sequence modelling to reduce false negatives

- Built using **Python, Flask, NumPy, Pandas, and Scikit-learn**
- Combined **KNN, Naive Bayes, Random Forest, and SVM** classifiers
